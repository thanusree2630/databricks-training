# Employee Database Analysis using Databricks SQL

## Overview
This project demonstrates SQL-based employee database analysis performed in Databricks/MySQL environment. Various SQL queries were executed to retrieve, filter, sort, and analyze employee records.

## Features
- Employee data retrieval
- Filtering records using conditions
- Sorting employee details
- Aggregate function analysis
- Salary-based insights

## Technologies Used
- Databricks
- MySQL
- SQL

## Database Details
The employee table contains:
- Employee ID
- Name
- Age
- Salary
- Department ID
- Hire Date

## SQL Operations Performed
- `SELECT`
- `WHERE`
- `ORDER BY`
- `COUNT()`
- `AVG()`
- `MAX()`
- `MIN()`

## Results
- Retrieved employee records successfully
- Calculated average salary
- Identified highest and lowest salaries
- Counted total employees

## Learning Outcome
This task improved understanding of:
- SQL query execution
- Data filtering and sorting
- Aggregate functions
- Database analysis in Databricks

## Conclusion
The project provided hands-on experience with SQL operations and employee database management using Databricks.
